# Ember Table Restaurant App

A complete React/Vite portfolio project designed as a menu-first restaurant ordering application.

## Included

- Complete redesign with no oversized landing-page hero
- Three-column desktop layout:
  - menu categories
  - dishes
  - restaurant and delivery information
- Separate food categories:
  - Breakfast
  - Starters
  - Main Course
  - Fish
  - Pizza
  - Desserts
- Separate drink categories:
  - Coffee
  - Tea
  - Matcha
  - Fresh Juices
  - Refreshers
  - Cocktails
  - Wine
  - Beer
  - Spirits
- Search and filters
- Favorites saved in localStorage
- Shopping cart saved in localStorage
- Quantity controls
- Product details
- Delivery, pickup and dine-in
- Complete ordering details:
  - full name
  - phone
  - email
  - street and building
  - apartment / intercom
  - city
  - postal code
  - delivery notes
  - payment method
- Demo checkout
- Mobile bottom navigation
- Light and dark themes
- English, Polish and Ukrainian
- Fallback images

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

This is a frontend portfolio demo. Real payments, order processing and address validation require a backend.


## Latest update

- All menu item names, descriptions, ingredients and allergens are localized in English, Polish and Ukrainian.
- All category labels and remaining interface text are localized.
- Drink categories and drink items are hidden when Delivery is selected.
- Existing drink items are excluded from the delivery cart total and delivery checkout.
